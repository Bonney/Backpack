Self-import of the module

LocalNotifications/NotificationContent.swift:1

import Backpack sits inside the Backpack module. Compiler warns: "file is part of module 'Backpack'; ignoring import".

Delete the line.

Calendar trigger missing .minute component

LocalNotifications/NotificationTrigger.swift:40

dateComponents([.second, .month, .hour, .day, .month, .year], from: date) lists .month twice and omits .minute. Calendar triggers will fire on the wrong minute.

// Should be:
let components = Calendar.current.dateComponents(
    [.year, .month, .day, .hour, .minute, .second],
    from: date
)
// Or, for a daily repeating alarm:
let components = Calendar.current.dateComponents([.hour, .minute], from: date)

SFSymbol typealias shadows the asset-name initializer

Extensions/Image+Symbol.swift

typealias SFSymbol = Image plus init(_ name: String) { self.init(systemName: name) } adds a same-signature initializer onto Image itself. Image("MyAsset") now silently looks up an SF Symbol instead of a bundled image.

Drop the typealias and either rename the init (init(systemSymbol:)) or put it on a distinct wrapper struct.

Retroactive Date: RawRepresentable conformance

Extensions/Date.swift:435

Compiler warning: "extension declares a conformance of imported type 'Date' to imported protocol 'RawRepresentable'; this will not behave correctly if the owners of 'Foundation' introduce this conformance in the future."

Wrap it in your own type for @AppStorage:

public struct StoredDate: RawRepresentable {
    public var date: Date
    public var rawValue: String { String(date.timeIntervalSinceReferenceDate) }
    public init?(rawValue: String) {
        guard let t = Double(rawValue) else { return nil }
        self.date = Date(timeIntervalSinceReferenceDate: t)
    }
}

Clear button stays hit-testable when invisible

Views/ClearButtonTextField.swift:60–66

Button is hidden with .opacity(0) but still accepts taps, and the empty-string check uses == "" rather than isEmpty.

let isEmpty = text.wrappedValue.isEmpty
clearButton
    .opacity(isEmpty ? 0 : 1)
    .allowsHitTesting(!isEmpty)
    .animation(.easeOut, value: isEmpty)

endOfDay / endOfWeek / endOfMonth / endOfYear are one second short

Extensions/Date.swift:108–115, 386–415

Returning 23:59:59 is not the end of the day; it breaks at leap seconds and DST transitions, and "less than endOfDay" checks miss the final second.

// Use Foundation's DateInterval — respects calendar & timezone:
var endOfDay: Date {
    Calendar.current.dateInterval(of: .day, for: self)?.end ?? self
}

Same pattern applies to startOfWeek, which currently hard-codes Monday by adding a day to Sunday. dateInterval(of: .weekOfYear, for:) respects the user's firstWeekday — matching the spirit of the recent gregorian-calendar fix.

Force-unwrap of optional Calendar.range

Extensions/Date.swift:147

range(of: .day, in: .month, for: date)! crashes when given a date the calendar can't resolve.

Return Int? or default to 0.

Swift 6 actor-isolation warning on logger

LocalNotifications/LocalNotifications.swift

Logger is referenced from nonisolated contexts but the class is @MainActor. Becomes a hard error under Swift 6.

Mark the static logger nonisolated or move it to file scope.

fatalError in Date(string:format:)

Extensions/Date.swift:165

Hard crash on parse failure. Fine for a debug assert, brutal for any client that ever loads user-supplied or remote strings.

Make the initializer failable (init?(string:format:)).

Outdated Use stdlib / modern SwiftUI

Each of these was useful at one point but is now covered by Foundation's FormatStyle APIs or a modern SwiftUI modifier. Deleting them shrinks the surface area without losing capability.

DateFormatter string properties

Extensions/Date.swift — relativeDateAndTime, shortWeekdayName, weekdayName, monthDayYear, monthDay, hourMinuteAMPM, monthYearString, dayNumber

Each allocates a fresh DateFormatter. All become localizable FormatStyle one-liners:

weekdayName       → self.formatted(.dateTime.weekday(.wide))
shortWeekdayName  → self.formatted(.dateTime.weekday(.abbreviated))
monthDayYear      → self.formatted(.dateTime.month().day().year())
hourMinuteAMPM    → self.formatted(.dateTime.hour().minute())
monthYearString   → self.formatted(.dateTime.month(.wide).year())

DateComponentsFormatter with force-unwrap

Extensions/Date.swift:186 (TimeInterval.format)

Force-unwraps string(from:)!. Replace with Swift's Duration:

Duration.seconds(self).formatted(.time(pattern: .minuteSecond))
// or .hourMinuteSecond when duration >= 3600

ControlSize table predates native modifiers

Hand-curated heights, paddings, shapes and fonts per ControlSize. SwiftUI's .controlSize(.extraLarge) and .buttonBorderShape(...) now cover most cases at your deployment target.

Reconsider whether this table still earns its keep.

TintColor environment value

Rationale (".tint has no environment value") is no longer true — SwiftUI exposes the active tint as a ShapeStyle.

Optional<Double>.isEmpty treats 0 as missing

Quick-win cleanup order

If you only have an hour, this sequence eliminates the loudest warnings and the highest-risk bugs first.

  1. Delete import Backpack from NotificationContent.swift.
  2. Fix the missing .minute in NotificationTrigger's dateComponents call.
  3. Rename or remove Image.init(_ name: String) — currently silently breaks asset lookups.
  4. Strip the redundant inner public in watchOS Colors.swift (silences ~85 warnings).
  5. Wrap or delete the Date: RawRepresentable conformance.
  6. Replace endOfDay / endOfWeek family with Calendar.dateInterval(of:for:).
